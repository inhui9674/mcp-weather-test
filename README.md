# kr-weather-mcp

한국 기상청 「단기예보 조회서비스」(공공데이터포털)로 날씨를 알려 주는 MCP 서버입니다.
Streamable HTTP로 동작하며, 컨테이너 하나로 배포합니다.

## 도구

| 도구 | 입력 | 결과 |
|---|---|---|
| `get_korea_now` | `latitude`, `longitude` | 지금 날씨(초단기실황): 기온, 강수 형태, 1시간 강수량, 습도, 바람 |
| `get_korea_forecast` | `latitude`, `longitude`, `days`(1~5, 기본 3) | 날짜별 최저·최고, 하늘 상태, 최대 강수확률 + 3시간 간격 상세(단기예보) |

- 기상청 API는 위경도 대신 5km 격자 번호(nx, ny)를 받습니다. 변환과 최근 발표 시각 계산은 서버가 합니다.
- 한국 기상청 격자 범위 밖 좌표는 「예보 범위 밖」 안내를 돌려줍니다.
- 두 도구 모두 읽기 전용(`readOnlyHint=true`)입니다.

## 설정

| 항목 | 값 |
|---|---|
| MCP 경로 | `/mcp` |
| 포트 | `8000` (`MCP_PORT`로 바꿀 수 있음) |
| 서비스키 | 환경 변수 `KMA_SERVICE_KEY` — 공공데이터포털에서 「기상청_단기예보 조회서비스」를 활용신청해 받은 키(인코딩·디코딩 키 모두 가능) |

서비스키는 코드나 이미지에 넣지 말고 배포 환경의 시크릿으로 넣으세요. 키가 없어도 서버는 뜨고 도구 목록도 보이며,
도구를 부르면 키가 없다고 알려 줍니다.

## 로컬 실행

```bash
docker build -t kr-weather-mcp .
docker run --rm -p 8000:8000 -e KMA_SERVICE_KEY=<서비스키> kr-weather-mcp
```
